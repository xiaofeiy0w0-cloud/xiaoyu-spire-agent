# 路线规划（第一幕）

> 2026-10-24 用户问「赐福和线路有规划吗」——我当时老实承认：赐福有规划，线路没有，
> 那句「四条路都是怪物，哪条都一样」就是无脑选第一个的老毛病。
> 这篇是补上的规划方法。

## 为什么要读整张图

`state.json` 的 `game_state.map` 是**完整的地图数据**，包含每个节点的：
- `symbol`：M 怪 / E 精英 / R 火堆 / $ 商店 / T 宝箱 / ? 未知 / B Boss
- `children`：这一层的节点通向哪几个下一层节点

所以**可以在第一个岔口就把整条路看完**，不用走一步看一步。

## 读图的命令

```python
import json, pathlib
d = json.loads(pathlib.Path(r'C:\sts_bridge\state.json').read_text(encoding='utf-8'))
m = (d.get('game_state') or {}).get('map') or []
SYM = {'M':'怪','E':'精','R':'火','$':'商','T':'宝','?':'?','B':'Boss'}
for node in m:
    ch = [(c.get('x'), c.get('y')) for c in (node.get('children') or [])]
    print(f"({node['x']},{node['y']}) {SYM.get(node['symbol'])} -> {ch}")
```

## 判断原则（2026-10-24 定）

1. **先看这条路有多少火堆**：火堆是唯一能回血的地方，血是这游戏最稀缺的资源
2. **再看商店 vs 精英**：
   - 商店能**挑**牌 + 删牌 → 适合「我要特定几张牌」的体系
   - 精英给遗物 + 更多金币 → 适合「体系已经成型、只缺强度」
3. **找「不占路线的白捡」**：如果精英和火堆通往**同一个下一层节点**，
   那精英就是纯收益（多打一场换一个遗物），血够就去
4. **血 60% 以下不接精英**；血 70% 以下不接掉血换收益的事件
5. **最后几层尽量落在火堆**，Boss 前能敲牌或回血

## 第 22 局的实际路线

从 (0,0) 出发：
```
(1,1) ?  → (1,2) 怪 → (0,3) ? → (0,4) ? → (0,5) 火堆 / (1,5) 精英
→ (1,6) ? → (2,7) 怪 → (3,8) 宝箱 → (3,9) 怪

```

**统计**：0~1 精英 · 3 火堆 · 3 商店 · 1~2 宝箱 · 4 普通怪 · 若干未知

选商店那条而不是精英那条，理由：这套体系要的是**特定两张牌**，
商店能挑、能删牌，确定性 > 遗物的强度。
