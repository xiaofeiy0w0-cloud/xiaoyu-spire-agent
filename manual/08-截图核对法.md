# 截图核对法（2026-10-24 用户提议）

> 用户原话：「我觉得你可以没事截图看一下操作是不是按你计划的那样进行，有没有什么东西被你漏掉了之类的。当你感觉不太对和 bug 的时候」

## 为什么需要它

我一直只靠 `state.json` 判断局面。但 `state.json` 是 mod 转述的，
**它可能有 bug、可能漏字段、也可能我把字段读错**。
截图是**独立信源**——两边的说法不一样，才说明有问题。

## 正确流程

1. **整图先看**：`python -X utf8 research\game.py shot` → 读 `turn.png`
2. **有疑问的地方裁切放大**再下结论：
   ```python
   from PIL import Image
   im = Image.open(r'<你的截图路径>\turn.png')
   im.crop((20, 62, 260, 120)).resize((960, 232), Image.LANCZOS).save(r'...\crop.png')
   ```
3. **才对比** state.json 和截图

★ **不要跳过第 2 步。** 我第一次就是直接看缩小后的整图，
把金币右边的三个**药水图标**看成了遗物，得出「state 少报了 3 个遗物」的错误结论。
裁切放大后：遗物只有 2 个，和 state.json 完全一致，**数据是对的**。

## 界面布局备忘（1286×749 窗口）

| 区域 | 位置 | 内容 |
|---|---|---|
| 角色名 + 血量 + 金币 | 顶部左侧 x≈20-350 | `fish the Watcher  70/72  💰99` |
| **药水** | 金币右侧 x≈355-490 | 最多 3 个图标 |
| **遗物** | **角色名下方** x≈20-260, y≈62-120 | 一排小图标 |
| 层数 | 顶部右侧 | `14` |
| 地图/标题 | 顶部中央 | 塔名 |

**遗物不在金币右边，在角色名下面。** 这是我认错图的直接原因。

## 什么时候一定要截图

- 打出/接受一张牌后，确认牌真的进了牌组
- 遗物、药水效果触发后，确认数值真的变了
- 怀疑某个数值算错（伤害、格挡、能量）
- 游戏行为和我读到的状态不一致
- 打完一局复盘时，对着截图核对有没有漏掉的东西
