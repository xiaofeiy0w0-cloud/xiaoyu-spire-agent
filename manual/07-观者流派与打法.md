# 观者（Watcher）四大流派 — 来自灰机 wiki「观者」页

> 2026-10-24 用户提议：「先去看看这个角色适合什么卡组，什么策略，然后有目的的玩一下试试」
> 这是第 21 局开始前的作战计划。

## 姿态机制（根基）

| 姿态 | 效果 |
|---|---|
| **愤怒** | 造成和受到**双倍**攻击伤害 |
| **平静** | **离开**这一姿态时，获得 2 点能量 |
| **神格** | **进入**时获得 3 点能量；造成**三倍**攻击伤害；下回合开始自动退出 |
| **真言** | 攒够 **10 层**自动进入神格；多余的真言会带到下一次 |

## 四个成型流派

### 1. 保留流派
防御向。靠「确立基础」降低卡牌费用，启动后打出一个超强回合。牌组偏技能牌。
**适合**：稳健、容错高。**不适合我**：爆发低，容易打成消耗战。

### 2. 预见流派 ★ 本局选择
- 幸运一击 / 斩破命运 / 天眼 的预见快速过滤牌库
- **配涅槃 → 获得护甲**
- **配迂回 → 单回合多次伤害**（预见时丢弃的迂回会立刻回到手牌）
- 预见能快速抓到 五体投地 / 祈祷，容易进神格打爆发
- 评估 / 祈祷 / 研习 洗进牌库的「洞见」配预见很好补手牌
- 化智为空 / 内心宁静 进出平静，补能量并抽牌
- **契合遗物**：双节棍、墨水瓶、开信刀、手里剑、精致折扇、**苦无**、两仪、日晷、算盘

### 3. 诸神之黄昏流派
围绕一张「诸神之黄昏」，用 斋戒 / 义愤填膺 堆伤害加成，等机会一击。
**风险**：前半局全靠苟，坟头草很高。

### 4. 无限 ★ 终极目标
**必需牌**：猛虎下山（1~2 张）＋ 一耗能进入平静的牌（如不惧妖邪）＋ 发泄

**循环**：
```
打出平静牌进入平静      （花 1 能量）
→ 打出发泄进入愤怒      （花 1 能量）
→ 离开平静 → 获得 2 能量
→ 猛虎下山触发 → 把「平静牌」和「发泄」抽回手
→ 重复，净花费 0
```
**伤害无穷大，费用净零。**

如果牌组里「非消耗且非能力」的牌少于 9 张，可以用任意一耗能进愤怒的牌替换发泄。

**强化**：心灵堡垒 / 以手拒之（格挡）、潦草急就（启动更快）、紫色莲花（每循环多 1 费）

## 第 21 局作战计划

- **主引擎**：预见 + 迂回（0 费伤害，每次预见后回手）
- **爆发**：五体投地 / 祈祷 / 虔信 → 攒 10 真言进神格
- **保命**：化拳为空 / 化体为空 / 内心宁静（主动退愤怒）
- **见到必拿**：猛虎下山、发泄、不惧妖邪（三张凑齐＝无限）
- **见到不拿**：同类第二张非核心牌（牌组要薄）

## 我要盯的三条（今天血的教训）

1. **开打前先看 `state` 的「★ 我身上的状态」**——虚弱 0.75 / 脆弱 0.75 / 易伤 1.5，不算这个所有斩杀线都是错的
2. **进精英前血要在 60% 以上**
3. **多目标战（史莱姆旧版/三哨卫）优先集火杀一只**，别平均分伤害

## ★ 最重要的理解修正

**「预见」这一个动作同时产生三样东西：**
1. **伤害** — 迂回从弃牌堆回到手牌（0 费，可以重复打）
2. **格挡** — 涅槃每次给 3 点
3. **滤牌** — 把不想抽的牌丢掉

所以预见流派不是「靠预见过牌」，而是**用一个动作同时解决输出和防御**。
这正好对应我两个死因：伤害不够、活不下来。
