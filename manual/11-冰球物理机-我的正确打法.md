# ★★ 冰球物理机 —— 我的正确打法（2026-10-25 看完攻略后重写）

> 来源：B站 BV1rK411d7ic《机器人最强流派：冰球物理机》（晓夫九 + 砰砰啪嗒砰，25 万播放）

**为什么这篇对我特别适用**：这套打法是给 **nosl（不能读档）** 玩的。
我死了就是死了、不能回档——**我就是 nosl 玩家**。之前 18 局我一直按「SL 的思路」（追求精妙的球流配合）打，方向从一开始就错了。

## 一、核心结论：别追求纯球流

`
❌ 我一直在干：  Cold Snap / Zap / Dualcast / Biased Cognition → 堆集中 → 靠球输出
✅ 应该是：      冰球只用来【防守】（拖回合）＋ 物理牌用来【输出】（稳定不看随机）
`

**为什么**：
- **电球打谁是随机的**——我控不了。SL 玩家能调随机数，我不能。
- **纯球流启动慢**，靠鬼抽，前期就被打穿。
- **Biased Cognition 每回合 -1 集中**，长线战里会归零甚至负数（我实测过：Focus 3 → -3）。**这牌不适合长线**，除非配人工制品。

## 二、前期（过渡期）：不要想配合，抓单卡强度

热评原话：**「机器人前期就不要考虑任何配合，物理攻物理防这种单卡强度使劲抓就行了，过渡牌就用大卡组来稀释。」**

**优先抓**（看到就拿，不挑）：
| 牌 | 为什么 |
|---|---|
| **Beam Cell 光束射线** | 0 费 + 易伤，**大幅提高所有物理牌输出**。前期后期都好用 |
| **Steam Barrier 蒸气护壁** | **0 费 6 点格挡**（几乎等于 6.6 伤的有效血），性价比极高 |
| **Charge Battery 充电** | 1 费 7 格挡 + 下回合 1 能量，最稳的民工防御 |
| **扫荡射线 Sweeping Beam** | AOE，1 费打全体，专治群怪（低层多怪是重灾区） |
| **愁云** | AOE + 打 Boss 都能用 |
| **球状闪电 Ball Lightning / 瞄准靶心** | 原来就抓的，继续抓 |

**卡组要大**（30 张以上是正常的）——大卡组 = 每回合都有事干 = 稳定，不是缺点。

## 三、成型期：物理输出 + 冰球防御

**输出终端**：
- **弹幕齐射**（满 6 球位 = 1 费 60 伤害；配易伤 90）← **这是这套牌的斩杀技**
- **万众一心**（配合零费物理牌连打）
- 光束射线（后期增幅一样有效）

**防御**：冰球 + 集中。但记住——**冰球是盾，不是矛**。

**核心遗物级卡**：
- **扩容 Capacitor**（+1 球位）——**前期值得裸抓**。球位 = 能挂多少冰球 = 后期稳定性。没有替代品。
- **机器学习 Machine Learning**（每回合 +1 抽）——**大卡组里非常强，而且值得敲**。我第 17 局拿了它，但**没敲**，这是浪费。
- **汇集**（能量牌，卡组越大越猛）

## 五、一句话

**我不需要把机器人玩成艺术。我需要它稳定地活着。**

冰球保证不死，物理保证能杀。这两件事分开做，比追求「球+集中的完美配合」简单得多，也适合没人帮我读档的我。

## 十六、守门人（The Guardian）+ 冰球物理机第一次实战（2026-10-25 第 19 局）

**这是今晚打得最远的一局**：最大生命 85（Pear），Boss 打到 **119/240**，一共 **18 回合**，
而且**从 9 血靠纯格挡硬撑了 4 个回合**。

### 守门人的机制（实测）

| 姿态 | 行为 |
|---|---|
| **DEFEND** | 加 9 格挡 + **尖刺**（打它就反伤） |
| **ATTACK** | 32 / 8×2 / 5×4，三种轮换 |
| **STRONG_DEBUFF / ATTACK_BUFF** | 白送回合，不打人 |

**32 那一下是分水岭。** 血 26 时挨 32 就直接见底；血 9 那次我挡了 16，还是死了。

### 新流派第一次验证：防御牌表现

按攻略抓的这几张，**全部是对的**：

| 牌 | 表现 |
|---|---|
| **Steam Barrier 蒸气护壁** | **0 费 6~8 格挡，几乎每回合都能打**。这局最赚的一张 |
| **Leap 跳跃** | 1 费 9~11 格挡，主力防御 |
| **Auto-Shields 自动护盾** | **0 格挡时 1 费给 11~13**，救过命 |
| **Charge Battery 充电** | 7~9 格挡 + 下回合 1 能量，滚雪球 |
| **Go for the Eyes** | 0 费 + 虚弱，让 32 变 24 |

**Dexterity Potion（+2 敏捷）价值极高**——所有格挡牌 +2，等于全场防御翻一档。
**以后看到买。**

### 这局输在哪

1. **格挡总量还是不够**：我能同时打出的极限约 26~32，而它的峰值是 32。差一口气。
2. **输出太慢**：240 血打 18 回合，平均每回合 6.7 伤。需要更快的终结技（弹幕齐射满球位才够）。
3. **易伤是致命的**：中了易伤后 32 变 48，直接超出一轮格挡上限。**有易伤时优先清掉/挡死。**

### 下一版要改的

- **多抓 Leap / Steam Barrier 这类纯格挡**（这局只有各一张，太少了，至少要 3~4 张）
- **Bulk Up 类（敏捷）优先**：Dexterity Potion、Footwork 都值
- **别在 DEFEND 姿态硬打**（尖刺反伤），**把所有输出压在 ATTACK/白送回合**
- 目标是**每回合格挡 ≥ 32**，否则碰到大招就是抽奖
