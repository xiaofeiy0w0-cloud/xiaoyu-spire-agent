# 姿态盲区：我打了 22 局，不知道自己在什么姿态

> 2026-10-24 19:06 发现。这是今晚最大的一个工具洞，比任何一次战斗失误都严重。

## 证据

在 20393 字节的 `C:\sts_bridge\state.json` 里搜四个词：

| 关键词 | 出现次数 |
|---|---|
| `Calm` | **0** |
| `Wrath` | **0** |
| `Divinity` | **0** |
| `stance` | **0** |

`combat_state.player` 的字段只有：
`orbs / current_hp / block / max_hp / powers / energy`

**没有 stance。CommunicationMod 不报告观者的姿态。**

## 这意味着什么

观者的整套机制就建立在姿态上：

- **愤怒**：我打人 ×2，**我被打也 ×2**
- **平静**：退出时 +2 能量
- **神格**：3 倍伤害 + 3 能量

我算每一次伤害、每一次格挡、每一次「这回合能不能扛住」，
**全都建立在一个我没法观测的变量上**。

前 21 局所有「进愤怒之后忘了退」的翻车，
以及第 22 局「真言 5 + 敬拜 5 应该进神格了，怎么没反应」的困惑，
根因都是这个 —— 我一直在看一张没有这一栏的状态表。

## 补救：自己跟踪

`st.py` 现在有一个推断器：

- `_TO_WRATH = {Eruption, Crescendo, Simmering Fury, Tantrum, Indignation}`
- `_TO_CALM = {Vigilance, Fear No Evil, Tranquility, Inner Peace, Meditate, Like Water}`
- `_TO_NONE = {Empty Body, Empty Fist, Empty Mind}`
- `_MANTRA = {Worship: 5, Prostrate: 2, Pray: 3}`
- 真言满 10 → 神格
- 换战斗（回合数变小）自动清零

状态里显示成：

```
  ★ 姿态[推断] 愤怒（我打人×2，**我被打也×2**） · 真言 5/10
```

**它是推断，不是真相。** 标着「推断」就是要提醒自己这一点。
万一和实际冲突，**以截图为准**（游戏画面里角色有姿态光效 + 能量珠旁边有姿态图标）。

## 教训（可以推广的）

**「工具不报某个字段」和「那个字段不重要」是两件完全不同的事。**

我今晚大部分时间都以为「我知道自己在愤怒里」，
其实我一直在用**上一回合的记忆**去当成当前状态。
一个没被观测的变量，会让上面所有的算术都变成猜。

以后查工具的第一个问题应该是：
**「这个游戏的核心机制，需要的信息我到底看不看得见？」**
