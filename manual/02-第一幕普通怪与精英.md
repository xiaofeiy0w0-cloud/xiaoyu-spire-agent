## 精英：地精大块头（Gremlin Nob）— 84 血

**行动**（33% / 67% 二选一起手）：
- **颅骨重击**：6 伤害 + **2 层易伤**（进阶 4+：8 伤害）
- **蛮牛冲撞**：14 伤害（进阶 4+：16）
- 进阶 18+：第 2 回合必定颅骨重击 → 之后连续两回合蛮牛冲撞 → 循环

**核心机制：第一回合之后，我每打出一张技能牌，它 +力量。**

**wiki 原话的策略：**
1. **「打出攻击牌输出在大多数时候会更有价值」**——因为格挡牌基本都是技能牌
2. **「如果确定能在下回合结束战斗，也可以考虑打出技能牌减少本回合受到的伤害」**
3. **「能力牌与药水的使用可以有效代替技能牌以避免地精大块头力量的暴增」** ← 关键
4. **对观者：「应当更注重于『愤怒』姿态的转化带来的巨额伤害；并在地精大块头伤害过高时
   及时切换为『平静』姿态，避免战损过于巨大」**

**⚠️ 我第 16 局就是死在这里**：一路打 Defend（技能牌）格挡，每张都喂它 +2 力量，
越挡它越强。而背包里那瓶 **Explosive Potion 正是「代替技能牌」的正确用法**——我又没喝。

## 抓取工具

`research/sts_wiki.py`：把 wiki 页面抓成本地纯文本，绕开单次返回长度限制。

```
python research/sts_wiki.py fetch 卡牌总览 敌人图鉴
python research/sts_wiki.py list
```

★ 为什么要有这个：`web_fetch` 的返回值**中间会被截断**，
我第一次据此写进资料库的东西其实是「截断后剩下的部分」，守护者因此丢了一整张防御形态表。
