# 状态数值表（虚弱 / 脆弱 / 易伤 / 力量 / 敏捷）

> ★ 2026-10-24 第 19 局血的教训：身上挂着 Frail 3 + Weakened 1，
> 我按「Strike 6 / Defend 5」算账，实际只打出 4 和 3。
> **每次「我算好了能挡住」都被打穿——不是运气，是我算的是错的数。**
> 现在 `st.py` 的 `state` 会打印 `★ 我身上的状态` 一行。

## 五个会改数值的状态（wiki 原文）

| 状态 | 效果 | 影响范围 |
|---|---|---|
| **虚弱** Weakened | 攻击造成的伤害 **-25%** | 只减「攻击」 |
| **脆弱** Frail | 从**卡牌**获得的格挡 **-25%** | 遗物/药水给的格挡不受影响 |
| **易伤** Vulnerable | 从攻击受到的伤害 **+50%** | 双向都放大 |
| **力量** Strength | 攻击伤害 **+X** | 多段攻击每一下都加 |
| **敏捷** Dexterity | 从卡牌获得的格挡 **+X** | |

## 实战算法

```
实际攻击伤害 = (基础伤害 + 力量) × (虚弱 ? 0.75 : 1) × (目标易伤 ? 1.5 : 1)
实际格挡     = (基础格挡 + 敏捷) × (脆弱 ? 0.75 : 1)
```

**向下取整。**

## 什么时候会被挂上

- **虚弱**：邪教徒（颅骨重击）、奴隶主、图书管理员、守护者的蒸汽喷射（2 层）
- **脆弱**：史莱姆的酸液、各种黏液
- **易伤**：精灵贵族的颅骨重击（2 层）、守护者的蒸汽喷射（2 层）
